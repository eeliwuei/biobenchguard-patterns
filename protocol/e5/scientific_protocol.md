# E5 scientific execution protocol for authentic wheat outcomes

The scientific parameters below were fixed before the E5 computation. This reader edition was prepared after execution from that recorded parameter freeze; it is not an external preregistration. Only object dimensions, missingness and source documentation were inspected before this plan. No E5 model fits, correlations, diagnostic scores or outcome-dependent choices were inspected. Historical E3/E4 used generated outcomes; this analysis retains all four authentic outcomes.

Dataset: the previously obtained BGLR `wheat.RData`, wheat.X (599 × 1279) and wheat.Y (599 × 4). Source: CIMMYT wheat data distributed by BGLR. The primary documentation describes standardized grain yield in four environments. The supplied outcomes include source aggregation and standardization; they are not raw plot yields. Dataset-specific redistribution permission is unestablished, so the source file is excluded from reader archives.

Phenotypes: report every supplied column, in stored order: `1`, `2`, `4`, `5`. No phenotype is selected by performance. No pooled best-outcome claim is permitted. The input and reader-protocol SHA256 values are recorded in `freeze.json`; its source_protocol_sha256 identifies the earlier execution freeze. Editing the exposition did not change any model, outcome-selection, split, seed, calibration or reporting parameter.

Model and preprocessing: Ridge(alpha=1, solver='cholesky'), with an intercept and 20 selected features. Predictor variance eligibility and model scaling are fitted using training observations. B selects the 20 eligible predictors with largest absolute training Pearson correlation with the authentic outcome. C selects using all authentic outcomes within the identical training-variable feature universe. Stable original-column order breaks ties. Scaling uses training population SD; no outcome transformation beyond the source-provided standardization. Missing values or unexpected dimensions cause failure; no adaptive imputation or tuning.

Validation: shuffled five-fold KFold, all 599 observations receiving exactly one held-out prediction per arm/reference. B and C use identical folds. Pooled OOF R-squared is the performance metric; T_scope = R2_C − R2_B. The target is random held-out lines from this fixed sample. This is not a new-family, new-environment or biological-population guarantee.

Candidate grid: L = 0, 400, 1000, 2500. Independent standard-normal candidate columns are generated as a (2500, 599) array and transposed; the first L columns give exact nesting. All phenotypes share split/candidate realizations, permitting descriptive paired comparisons without treating phenotypes as independent biological replications. Candidates are a controlled perturbation, not naturally occurring biological measurements.

Reference law: authentic X and each authentic y are fixed. Only KFold partitions and, for L > 0, candidate pools are randomized. There are 100 independent calibration reference IDs at L=0, and 100 independent evaluation IDs evaluated at every L. Calibration and evaluation RNG streams and IDs are disjoint. Repeated partitions do not create new lines, datasets, biological cohorts or independent phenotypes. L=0 still includes C's full-label selection; it is not a clean-pipeline null.

Seeds: SHA256 of the UTF-8 string `patterns-v14-e5|20260908|ROLE|INDEX|STREAM`, first 8 bytes interpreted little-endian modulo 2**32; ROLE is `calibration` or `evaluation`; INDEX is 0–99; STREAM is `folds` or `candidates`. KFold receives the folds seed; candidates use NumPy default_rng with the candidates seed. No reruns with different seeds to obtain a favorable result.

Calibration and comparator: for each phenotype, sort its 100 calibration L=0 scores and select rank ceil(101 × .95) = 96 (one-based). Alert iff T_scope > tau; ties do not alert. The same-law marginal bound is 5/101 over both calibration and evaluation randomness, not a conditional biological false-positive rate of .05. The fixed comparator alerts iff T_scope > .05; .05 is an analyst-defined screening comparator, not a literature standard.

Decisions: an alert may motivate examination of sensitivity to supervised selection. A non-alert only describes this reference comparison and never permits a known full-label selection workflow. Correct conventional provenance inspection requires excluding or repairing C at every L, regardless of either score. Only B is eligible for a deployable model. No model-selection or deployment benefit is assumed.

Success/failure: numerical disagreement between screens is descriptive. To meet the substantive additional decision-utility utility gate, a result would additionally need a defensible, consequential practitioner action beyond correctly executed provenance inspection and target-matched validation on an untouched real benchmark. Merely changing a numerical alarm under injected candidates does not meet that gate. If this experiment supplies no such evidence, retain the bounded CRC conclusion and report additional practitioner utility as not demonstrated; do not call the new exercise a successful utility demonstration.

Uncertainty: report exact attempted, successful, failed and excluded reference counts. Each operating rate uses its actual evaluation denominator and a two-sided 95% Wilson interval conditional on the fitted cutoff and fixed X,y. Use 2000 bootstrap draws, seed 2026090814, independently resampling calibration IDs and paired evaluation IDs and recomputing thresholds, rates and paired calibrated-minus-fixed rate differences. Percentile endpoints use NumPy method='linear'. These quantify algorithmic randomization and calibration uncertainty, not biological sampling or model-refit population uncertainty. No multiplicity-controlled discoveries or independent-phenotype meta-analysis.

Reporting and reproducibility: save fold IDs, both OOF predictions, full-precision scores, seeds, selected-feature IDs, raw/protocol/code hashes, failures and environment versions; provide all four outcome tables and a data-derived figure. A separately created process reruns the entire E5 computation with the same raw inputs, seeds and pinned environment; compare numerical arrays and actions at tolerance 1e-10. Retain failures and any discrepant result. No scientific conclusion is selected after seeing the result.
